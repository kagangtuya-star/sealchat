# 《乐园》幕布房间 · 孔版会志版 · 使用文档

> 忍神（シノビガミ）· 现代篇 · 特殊型 ／ 原作 河岛陶一朗 · 译 透
> 风格概念：**「孔版会志《乐园》，第 N 刷」**——整个房间是同好会为文化祭赶印的一本 Risograph（孔版）会志封面。它每一巡都被重新印刷一遍，奥付上每一刷的发行日都是九月三十日。

本版按 `skills/sealchat-theater-room` 的「风格立项」流程重新设计，与 `rooms/paradise/`（黑板教室版）是同一模组的两套独立房间，可以任选其一。

## 1. 风格立项

### 1.1 三个方向（概念卡）

| | 稳妥：文化祭场刊 | 跳出：循环的接触印样 | **激进：孔版会志 · 第 N 刷（选定）** |
| --- | --- | --- | --- |
| 概念句 | 房间是清陵祭的官方导览手册 | 房间是一张胶片接触印样，同一天的 36 帧排成格子 | 房间是同好会赶印的会志封面，每一巡都被重印一次 |
| 主窗 | 校园地图上的"现在位置" | 被红色油性笔圈出的那一帧 | 封面配图框，四角是裁切线（トンボ） |
| 配色 | 学校蓝 + 杏黄 | 黑白胶片 + 红笔 | 再生纸 + 荧光粉 + 蓝，两版叠印出紫 |
| 字体 | 圆黑体、节目表 | 胶片边码、手写 | 海报黑体巨字 + 等宽字（Space Mono） |
| 标志性叙事动效 | 图钉移动 | 每巡多叠一次曝光；惨剧时一帧过曝烧白 | 时牢发动 = 再印刷，奥付续上"第 N 刷 · 九月三十日" |
| 对话框 | 节目单的一栏 | 底片条 | 从会志上剪下的一条 |

**选定理由**：
- **世界内媒介**：文化祭前夜，学生在印刷室赶印传单、会志，这正是"文化祭的前一天"会出现的东西。谜团「文化祭的小道具——同好会公开发表的东西」也和它对得上（只是呼应，不剧透）。
- **机制即版式**：循环被翻译成"重印"。同一张版、同一个日期，一刷又一刷；印得越多，墨越不匀、套色越偏。
- **反差**：用最甜、最荧光的学生印刷品讲一个每巡都有人被杀的循环。粉色既是告白与青春，也是卡纸时溅开的血。
- 另外两个方向：场刊方向只是换了媒介的"信息板"，机制没有长进版式；接触印样方向很强，但黑白胶片和"文化祭前夜"的甜味关系较弱。

### 1.2 视觉发明（只属于这个房间）

| 发明 | 落在哪里 | 叙事作用 |
| --- | --- | --- |
| **奥付"第 N 刷"** | 右翼奥付；时牢发动时用订正贴纸续写 | 每一刷的发行日都是九月三十日。结局·时间流动：一张订正贴纸把"初版 九月三十日"改成"第 2 版 十月一日"；结局·永远的乐园：贴纸一路叠到第 ∞ 刷 |
| **套色错位** | 所有组件；主舞台的粉版会隔一阵轻微跑位 | 两块版"差一点点对齐"，像被印了太多次的东西 |
| **吃墨不匀** | 特效层常驻 | 第二巡起两翼出现漏墨白条，一巡比一巡多；第三巡后偶尔闪过一道粉色辊痕 |
| **卡纸** | 惨剧 | 屏幕一震，粉墨被拖成一道长痕、往下滴，纸面起皱，"E-30 卡纸" |
| **密封页（袋とじ）** | 谜团公开；资料夹谜团页 | 剪刀沿虚线剪开，封页翻起，露出谜团 |
| **撕裂** | 高潮 | 纸从中间撕开，露出深蓝夜色和荧光粉边 |

### 1.3 母题与配色

| 母题 | 落在哪里 | 叙事作用 |
| --- | --- | --- |
| 期号 **No.30** / 页码 **— 30 —** | 左翼期号、页脚 | 九月三十日 |
| 标语「明天，就是文化祭。」 | 左翼竖排，荧光笔划过 | 明天永远不来；夜版被一道粉线划掉 |
| 社团教室的窗 | 主窗配图（无场景图时） | 日：夕光网点；夜：窗框成为纸色剪影 |
| 网点太阳 → 网点月亮 | 右上出血 | 日景是粉色太阳，夜景换成月光蓝的满月（「月读」的伏笔，只是象征） |
| 兔子印章 | 左翼、序幕、对话框右下 | 同好会吉祥物印章（「契兔」与月的伏笔，只是象征） |
| 打孔纸屑 | 氛围层 | 文化祭的甜；夜景倒着往上飘 |
| 订书钉、裁切线、套准标记、色标 | 版面四周 | "这是一件印刷品" |

配色：再生纸 `#F3EEE2` · 荧光粉 `#FF48B0` · 蓝 `#0078BF`。粉版用正片叠底，与蓝版重叠处自然叠成紫，这里有意打破"1 底 + 1 线 + 1 点"，用孔版套色本身的第三色。夜版是"印在深蓝色纸上"：纸 `#141A3D`、荧光粉、月光蓝 `#9AB8EE`，叠加方式改为滤色。构图与日版完全一致。

**防剧透原则**：房间只放公开信息，包括导入 HO 的【使命】、NPC 公开形象、人格面具规则、秘宝公开描述、谜团（公开前封在密封页里），以及导入①中 GM 公开描述的忍务。所有【秘密】、薰与真琴的真实身份、时牢的解除条件与暗号都**没有**写进任何组件或对话框底图。

## 3. 搭建步骤（SealChat）

### 3.1 创建 iForm

为每个组件新建一个 iForm，名称建议 `乐园孔版·序幕`、`乐园孔版·主舞台日` 等。打开对应 `.html`，全选复制，粘贴到「嵌入代码」。

- `04-core.html` 与 `05-dossier.html`：打开「Embed API → 启用」。新建 iForm 的默认能力已包含 `storage.read, storage.write, events.subscribe, events.publish, permissions.read`；旧 iForm 需要手动补齐。
- 夜景的氛围层：再建一个 iForm，把 `06-ambient.html` 顶部 `CONFIG.mode` 改为 `'night'` 后粘贴。

### 3.2 三个小剧场场景

| 场景 | 放入的网页对象（自下而上） |
| --- | --- |
| **序幕** | `乐园孔版·序幕`（铺满） |
| **清陵学园** | `主舞台日`（铺满）→ 场景图（可选，对齐主窗）→ 立绘 / 对话框 → `氛围`（铺满）→ `目次`（右翼）→ `时牢`（铺满，最上层） |
| **终焉之夜** | `主舞台夜`（铺满）→ 战斗图（可选）→ 立绘 → `氛围·夜`（铺满）→ `目次` → `时牢`（铺满，最上层） |

添加方法：舞台「添加网页」→ 选中对象 →「快速添加内置工具」→「频道嵌入」选对应 iForm。背景、氛围、时牢特效层**不可交互**；目次、控制台**可交互**。同一个 iForm 在多个场景各放一份，状态共享。

> 序幕的最后一帧就是会志封面，切到「清陵学园」时画面自然接上。

### 3.4 时牢核心：同一个 iForm 用两次

`04-core.html` 按自身宽度切换角色：
- **特效层**（宽 ≥ 800px）：舞台上铺满、置顶、不可交互。
- **操作面板**（宽 < 800px）：GM 在聊天侧以浮窗打开（约 420×660），玩家看不到；只有 World Owner/Admin 能看到按钮。

| 项 | 日版（清陵学园） | 夜版（终焉之夜） |

## 5. 自定义

- 社团名：`02` / `03` / `01` 的 `CONFIG.club`（例如 `'轻音同好会'`）。PL 决定社团活动后改一下，会志就成了"他们的"会志。
- 标语、图注、部员名单：`02` / `03` 的 `CONFIG.tagline / caption / members`。
- `04-core.html`：`tragedyText`（卡纸字幕）、`mysteries`（密封页内容）、`sceneKinds`、`rounds`。
- `05-dossier.html`：`DATA.tabs` 增删页；卡片 `sealed: true` = 密封页，`reveal` = GM 剪开后才显示的段落。
- `06-ambient.html`：`mode`、`density`、`avoidCenter`。
- 模组变体（混合型 / 经验型）：房间只用公开信息，可以直接沿用。

## 6. 注意事项

- **字体**：从 Google Fonts 非阻塞加载站酷庆科黄油体、思源黑体与 Space Mono；不可达时回退系统黑体与等宽字，版式不变。
- **性能**：网点在加载时一次性生成为 SVG path；氛围层是单个 canvas，粒子数随舞台面积自适应，上限 48。系统开启"减少动态效果"时，位移类动效会关闭。
- **沙箱**：未使用 `alert/confirm`；`localStorage` 全部 try；危险操作改为"按两次确认"。
- **未启用 Embed API** 时，操作面板显示「未启用 Embed API」，操作不会同步。

## 7. 本地预览

```bash
python3 -m http.server 8790   # 在仓库根目录运行
```

访问 `http://127.0.0.1:8790/rooms/paradise-riso/`：左侧是模拟舞台，可以切换三个场景、开关图层、叠示例场景图与对话框；右侧是 GM 浮窗操作面板，可以勾选"以玩家视角查看"。
