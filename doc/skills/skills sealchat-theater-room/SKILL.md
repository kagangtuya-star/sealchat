# SealChat 小剧场房间设计

把一个 TRPG 模组翻译成一套只属于它的"幕布"：从模组的世界、机制和象征里长出一种平面设计语言，配合入场、持续、叙事三类动效，全部以单文件 HTML 组件形式挂到 SealChat 小剧场；再用同一种视觉语言画一张对话框底图，让立绘对话也在同一个世界里。

**大胆创新是默认值。** 参考原型（车票、星图、怀表、卷轴、黑板……）和模板的主题 / 边框参数都是"已经存在的答案"：用来对照、借零件、写工程骨架，不用来圈定风格。每个房间都要能"遮住标题也认得出是这个模组"，并至少有一个只属于它的视觉发明。唯一不能打破的是硬约束（主窗可用、底部安静、对话框可读、秘密不上墙、平台限制）。

## 先读

1. `references/design-essence.md` —— 硬约束、**风格生成法（五个生成源、发散→收敛、新意自检、示例）**、参考原型与可打破的惯例（版面、色彩、质感、排版、动效）、反模式。**设计前必读，重点是第 3 节。**
2. `references/sealchat-stage.md` —— 平台硬约束：88192 字节上限、sandbox、Storage/Events 按 iForm 隔离、"一个 iForm 按尺寸切换角色"、层级。
3. `references/room-workflow.md` —— 从模组到房间的 8 步流程与实现规范（含踩坑清单）。
4. `references/component-catalog.md` —— 模板组件的配置项与运行时 API。
5. `references/dialogue-box.md` —— 对话框底图：SealChat 规格（1920×336、名字/正文/按钮区）、与房间同源的方法、导出流程。

## 流程速览

1. **情报分级**：公开 / GM 专用 / 秘密三栏。房间对玩家全程可见，**秘密、真实身份、解除条件、暗号永不上墙**，只用象征埋伏笔。
2. **素材清单**：地点与时间、机制、真相的象征、世界里的媒介与材质，尽量多列。
3. **风格立项**：用五个生成源（世界内媒介 / 机制即版式 / 平面设计流派与工艺 / 材质与光 / 反差与错置）发散出**至少 3 个差异很大的方向**，写成概念卡；新意自检后**默认选最大胆且满足硬约束的方向**，分歧大时让用户选。再分配物件角色（主窗、计数、持续动效、标志性叙事动效）并定色。
4. **规划场景与事件**：大氛围切换用小剧场场景（挂载即播放），叙事节点用 Events（GM 触发，全员同步），结果写 Storage（迟到者可见）。
5. **组件**：从 `templates/` 取工程骨架，视觉按立项方向重写；主背景、开场、标志性叙事动效默认手绘专属版本。
6. **实现**：1920×1080 画布等比覆盖缩放，主窗默认 960×540 @ (480,140)（可按方向调整并写进 README）；需要同步的组件放 `<sealstage-runtime>` 占位后运行 `scripts/sync_runtime.py`。
7. **对话框**：用房间的视觉语言画对话框底图（以 `templates/dialogue-box.html` 的规格为骨架手绘专属版），`scripts/export_png.py` 导出透明 PNG。
8. **验证**：`scripts/check_embed.py`；写本地预览台在浏览器里逐个触发事件、定格动画截图；对话框放进舞台合成预览检查；按三栏清单通读所有可见文字；对照截图再做一次新意自检。
9. **交付**：组件 HTML + 对话框 PNG + README（风格概念、iForm 设置、场景搭建表、主窗坐标、对话框设置、"模组进程 × GM 操作 × 玩家看到"对照表）。

## 模板

模板是**工程骨架 + 快速草案**：缩放、运行时、同步、角色切换、对话框规格与导出可以直接复用；主题、边框、母题、粒子预设只在用户要快速出图或次要组件时直接套用，正式房间的视觉不受这些参数限制。

| 文件 | 角色 | 交互 | 同步 |
| --- | --- | --- | --- |
| `templates/frame.html` | 主背景：4 种主窗边框 × 7 种母题 × 6 主题 | 否 | 否 |
| `templates/opening.html` | 开场揭幕：墨晕→纹章→书写→落印 | 否 | 否 |
| `templates/ambient.html` | 氛围粒子（14 种，可组合、可倒流） | 否 | 否 |
| `templates/dossier.html` | 资料夹：吊签菜单、规则表掷骰、HO 翻面卡、GM 公开卡 | 是 | 是 |
| `templates/stage-core.html` | 演出核心：控制台 / 特效层双角色（幕名横幅、计数印章、字卡、闪光） | 控制台是 | 是 |
| `templates/dialogue-box.html` | 对话框底图设计源：5 种边框 × 6 主题，参考线 + 示例文字；导出为透明 PNG（不是 iForm 组件） | — | — |
| `templates/runtime.js` | SealStage 运行时（Embed SDK 优先，本地回落 BroadcastChannel） | — | — |

## 完整实例

`examples/paradise/`（指向仓库 `rooms/paradise/`）：忍神模组《乐园》的整套房间——多段分镜序幕、日/夜同构主舞台、时牢核心（倒转大钟、红线断裂、谜团翻牌、玻璃碎裂、八岐、双结局常驻卡、「正」字计数）、资料夹、氛围层、黑板对话框底图（`07-dialogue-box.html` → `dialogue-box.png`）、本地预览台与使用文档。做新房间时打开它的 `index.html` 与 `README.md` 参考工程做法（分镜、同步、预览台、文档结构），不要复制它的黑板 / 和风视觉。

## 脚本

```bash
python3 scripts/sync_runtime.py <html 或目录>   # 注入/更新 SealStage 运行时
python3 scripts/check_embed.py <html 或目录>    # 嵌入约束检查（有 ERROR 退出码为 1）
python3 scripts/export_png.py <html> <out.png> [--size 1920x336] [--query "theme=..&frame=.."]   # 无头 Chrome 导出透明 PNG 并校验
```

## 不可违反

- 单个组件 ≤ 88192 字节（UTF-8）。
- 不用 `alert/confirm/prompt`；`localStorage` 必须 try；不 `<script src>` 外部脚本（SDK 由运行时按宿主配置动态加载）。
- 叠加层背景透明并声明 `color-scheme`；全屏层不可交互，可点击的组件做小尺寸。
- 需要联动的界面放进同一个 iForm（Storage/Events 不跨 iForm）。
- 不把任何秘密写进房间（对话框底图同样全程可见）。
- 对话框底图宽高比与对话框一致（默认 1920×336），右上角按钮区保持安静，名札用深底衬角色色。
