# 幕布房间设计精髓

> 跑团房间的气质可以千差万别，好房间的共同点不是"长得像某种风格"，而是**一眼就认得出是这个模组**。本文分三层：
> 1. **硬约束**（第 2 节）——功能性要求，任何风格都必须满足；
> 2. **风格生成法**（第 3 节）——从模组内容里长出这一个房间独有的平面设计语言，这是设计的主体；
> 3. **惯例与参考原型**（第 1、4–8 节）——前人验证过的好用做法，可以借用，也可以有理由地打破。
>
> 预设原型、模板主题和边框都只是"已经存在的答案"。新房间默认不直接套用，而是把它们当作**不要重复的基线**和**实现时的工程参考**。

## 1. 参考原型（基线，不是菜单）

下表是已经做过的方案，说明"一个模组物件如何变成整套 UI"。用法：
- **对照**：新方案如果和其中某行只差配色，说明还没想出东西，回到第 3 节继续发散。
- **借零件**：可以借某一格（比如"剪线分 HO 位"），但不要整行照搬。
- **兜底**：只有用户明确要求快速出图、或组件是次要的临时房间，才直接按原型套 `templates/` 的主题参数。

"边框 · 主题"一列对应 `templates/frame.html` 与 `templates/dialogue-box.html` 的 `frame` / `theme` 参数。

| 原型 | 适合题材 | 色彩（底 / 线 / 点） | 主窗物件 → UI | 持续动效 | 边框 · 主题 |
| --- | --- | --- | --- | --- | --- |
| **怪谈车票** | 都市传说、单程旅途 | 纸白 / 墨黑 / 朱红 | **车票**＝主框；剪线把框分成两个 HO 位；脉搏线＝生死；月相环＝时间 | 月相环缓慢公转，花枝线稿 | `ticket` · `ink` |
| **星图屏幕** | 克苏鲁、科幻神秘 | 纯黑 / 线白 / 深蓝 | 星空**屏幕**＝主框；星盘、齿轮、点阵地图拼贴；拉丁字母菜单 | 星盘自转、流星、吊星摇晃 | `screen` · `cosmic` |

| **卷轴花窗** | 国风、武侠 | 墨褐 / 古金 / 朱红 | 卷轴**中窗**；红色竖签菜单；左右**花窗**＝两个 HO 位 | 梅枝、云气流动 | `lattice` · `classic` |
| **视差远景** | 仙侠、旅途 | 夜色散景 / 青蓝 / 橘红 | 无框，**多层视差**；山、伞、飞鸟、多重月亮＋**水面倒影**；竖排诗句 | 涟漪、鸟群、倒影晃动 | `screen` · `cosmic` |
| **和纸 HO 卡** | 忍神等对立型 | 和纸粉 / 赭红 / 朱红 | 顶部**照片窗**；**HO 卡 壹贰叁肆**；居中规则表按钮；一翼模组信息 | 海浪纹、竖排诗句 | `lattice` · `washi` |
| **黑板教室** | 校园、日常崩坏 | 暮色 / 墨紫 / 朱红 | **黑板**＝主框；日历＝计数；文化祭装饰＝甜；红线＝羁绊 | 赤蜻蜓、夕光尘埃、倒走的钟 | `board` · `school` |

注意"适合题材"一列只是历史记录，**不是选型规则**：克苏鲁不必是星空黑，校园不必是黑板。按题材标签选风格正是要避免的定式。

## 2. 硬约束（任何风格都必须满足）

这些是功能，不是审美，打破它们房间就不能用：

1. **主窗可用**：舞台上有一块清晰、低干扰的区域放场景图 / 立绘（默认 960×540 @ (480,140)）。主窗的位置、尺寸、形状都可以改，但改了要在 README 写明坐标，且中心不放持续动效和高对比装饰。
2. **底部安静**：对话框区域（舞台 y ≈ 745 以下）不放抢眼元素。
3. **信息可找到**：标题、模组信息、规则表、HO 这四类信息玩家要能找到；以什么形式出现（卷宗页、收音机频道、货架标签、棋谱注记……）完全自由。
4. **对话框同源且可读**：对话框底图与房间同一视觉语言，名字区、正文区可读，右上角按钮区安静（规格见 `dialogue-box.md`）。
5. **秘密不上墙**：房间与对话框全程对玩家可见，只用象征埋伏笔。
6. **平台约束**：体积、沙箱、透明背景、`prefers-reduced-motion` 等，见 `sealchat-stage.md` 与 SKILL.md「不可违反」。

## 3. 风格生成：从模组长出视觉语言（核心）

### 3.1 原则

- **风格从模组内部来，不从题材标签来。** "和风 → 和纸朱红""克苏鲁 → 星空""校园 → 黑板"都是定式。要问的是：这个模组的世界里，有什么只有它才有的东西？
- **房间本身可以是故事世界里的一件物品。** 不是"画一个有边框的背景"，而是"玩家坐在什么东西前面"：一份案件卷宗、一台旧电视、一张被涂改的地图、一本祭典手册。
- **机制要长成版式。** 时限、循环、对立、侵蚀、隐藏信息这些规则，应当直接决定版面结构和事件动效，而不只是换个计数器图标。
- **至少一个视觉发明。** 每个房间要有一样别的房间没有的东西：专属的版式机制、专属材质、专属的叙事动效。

### 3.2 五个生成源

逐条过一遍模组，每条至少写出 2–3 个候选，再组合：

| 生成源 | 问自己 | 例 |
| --- | --- | --- |
| **世界内媒介** | 故事世界里，什么印刷品 / 器物 / 界面最可能承载这些信息？ | 报纸号外、病历与 X 光片、列车时刻表、当铺账本、经卷、游戏卡带说明书、电报、乐谱、热敏小票、寻人启事、天气图、地铁线路图、邮票与邮戳、电台节目表、塔罗牌、自动售货机面板、拍卖图录、植物标本册 |
| **机制即版式** | 规则怎样变成版面结构或会随剧情改变的版面？ | 循环 → 版面每巡被"再复印一次"，越来越糊、错位；侵蚀 → 版面被虫蛀 / 被水泡开，随轮次扩大；对立 HO → 左右两半用不同印刷工艺；隐藏信息 → 涂黑条、刮刮层、背面透字；投票 → 选票与计票板；倒计时 → 燃烧的线香 / 漏到底的沙 |
| **平面设计流派与工艺** | 哪种设计语言和这个故事的时代、情绪或主题有"内在关系"？ | 瑞士国际主义网格、俄国构成主义、包豪斯、装饰艺术、孟菲斯、新浪潮（David Carson）、Y2K / 蒸汽波、Risograph 套色错位、丝网、凸版活字、木刻与铜版、浮世绘、剪纸、月份牌、昭和看板、70 年代杂志、zine 拼贴、ASCII / 终端、像素、工程蓝图、解剖图、博物图鉴、星图、等高线地形图 |
| **材质与光** | 如果房间能摸到，它是什么手感？光从哪来？ | 霓虹管、磨砂玻璃、锈铁、胶片颗粒与划痕、X 光片、热敏纸褪色、烫金、蜡封、刺绣针脚、彩色玻璃、水下焦散、雪地、烟、荧光墨在黑光下 |
| **反差与错置** | 用与题材"相反"的语言会不会更锋利？ | 恐怖用甜美幼儿绘本 / 超市促销海报；末日用旅行社宣传单；修仙用产品说明书或工程图；悲剧用欢快的运动会节目单；宫斗用棋谱 |

### 3.3 发散 → 收敛

1. **发散**：从 3.2 组合出**至少 3 个彼此差异很大的方向**：
   - 一个"稳妥"方向（可以借参考原型的零件）；
   - 一个"跳出"方向（换掉媒介或工艺，不在第 1 节任何原型里）；
   - 一个"激进"方向（反差、错置或让机制彻底改写版面）。
2. **每个方向写成一张概念卡**：
   - **概念句**：一句话说清"玩家坐在什么东西前面"（例："整个房间是一张不断被复印的寻人启事"）；
   - **主窗**是什么（可以不是边框：可以是透镜、破洞、留白、画中画、显示器、取景器）；
   - **配色**与**字体策略**；
   - **一个标志性叙事动效**（GM 触发时最难忘的那一下）；
   - **对话框**会长什么样。
3. **收敛**：用 3.4 自检给每个方向打分，**默认选最大胆、且满足第 2 节全部硬约束的那个**。稳妥方向只在大胆方向确实不可行（可读性、体积、实现成本）时才用，并在交付说明里写明原因。
4. **方向分歧会显著影响全局时**（例如用户可能有强烈题材预期），先把 3 张概念卡（可附小尺寸草图）给用户选，再进入实现。

### 3.4 新意自检

- **遮住标题，还认得出是这个模组吗？** 换一个同题材模组也能用的方案，不合格。
- **和第 1 节原型、已有房间撞型吗？** 只差配色 / 换了母题图案，等于没改。
- **有没有"只属于这个模组"的视觉发明？** 指得出具体是哪一个。
- **至少打破了一条惯例吗？**（第 4–7 节任意一条：两翼、出血、竖排、印章、"1 底 1 线 1 点"、主窗是边框……）说得出为什么打破。
- **硬约束全部满足吗？** 新意不能以主窗不可用、对话框读不清、秘密上墙为代价。

### 3.5 示例（虚构，演示思路）

| 模组核心 | 定式做法 | 生成后的方向 | 视觉发明 |
| --- | --- | --- | --- |
| 时间循环的小镇失踪案 | 倒转的钟 + 夜色 | **反复复印的寻人启事**：黑白复印纸、网点照片、手写电话号码撕条 | 每巡切换时版面"再复印一次"：对比度下降、噪点增加、整体轻微错位；计数＝右上角复印份数编号 |
| 深海调查（克苏鲁） | 星空屏幕 | **被海水泡烂的调查笔记**：蓝黑钢笔字、纸张起皱、水渍边 | SAN 检定失败时，墨迹沿水渍晕开，局部文字化成触须状的墨流 |
| 宫廷权谋 | 卷轴花窗 | **一局围棋的棋谱**：网格、黑白、手数编号；HO＝四个角的星位 | 每个叙事事件是一次"落子"，棋盘上逐步出现的形状本身就是伏笔 |
| 便利店都市怪谈 | 车票 + 朱红 | **热敏小票**：竖长打印条、时间戳、条形码、等宽字 | 开场是小票逐行打印；高潮时小票像热敏纸受热一样整体发黑 |
| 末日方舟船票争夺 | 星图 / 废土锈铁 | **旅行社彩色宣传单**：过饱和照片、促销爆炸贴、"仅剩 4 席" | 剩余席位用促销价签计数，被划掉重写；灾难事件时宣传单被雨淋透、颜色流走 |

## 4. 惯例：版面结构

下面是参考原型共有的结构，好用，但不是唯一解。打破时要满足第 2 节。

1. **主窗是剧情物件**：车票、怀表、卷轴、屏幕、黑板、花窗——比普通矩形强。更进一步，主窗也可以是透镜、取景器、破洞、报纸上的配图、电视画面，或者干脆是一块被版面"让出来"的留白。
2. **两翼**：左右放标题、模组信息、菜单、HO，不对称也要重量平衡。替代方案：顶部报头 + 底部栏、四角分布、整页网格、单侧长条（时刻表 / 小票）。
3. **出血装饰**：大号母题物从边缘切入，制造"画框外还有世界"。替代方案：严格网格内不出血（瑞士风）、版面本身被裁切（局部放大的物件）。
4. **幕与场**：多幕模组需要可识别的切幕信号。横幅只是一种，也可以是换版次、翻页、换频道、重新复印。
5. **高潮变体**：切幕 / 高潮时保持构图、改变底色与点缀明度，玩家仍认得出"是同一个房间"。也可以让版面"损坏"或"变质"，只要结构仍可辨认。

## 5. 色彩

- **颜色要有叙事意义**：怪谈车票的红＝血与车票；侦查拼贴的蓝＝冥河之水；乐园的红＝告白与死亡。这一条是原则。
- **"1 底 + 1 线 + 1 点"是默认值**：点缀色占画面 5–10%，最稳。也可以有意打破：Risograph 两色套印叠出第三色、全单色 + 一处荧光、Y2K 的高饱和渐变、复印机的纯黑白。打破时要能说出颜色在讲什么。
- 任何配色都要验证：主窗附近低干扰，对话框名字（角色色）与正文可读。

## 6. 质感

- 纸纹（washi 纤维、噪点）、网点（halftone）、墨渍飞白、胶带、钉孔、折痕是纸本类风格的常用手段；第 3.2 节的材质表提供更多方向（胶片、玻璃、金属、织物、光）。
- 程序化生成优先：SVG `feTurbulence` / `feDisplacementMap` 噪声与变形、`radial-gradient` 网点、`mask` 刷痕、`mix-blend-mode` 套色错位、canvas 颗粒，都不依赖位图。
- 线稿和矢量的好处是可缩放、可描边动画、可换色；需要写实位图时用舞台图片对象承载，不塞进嵌入代码。

## 7. 排版

- 字体策略跟着媒介走：经卷 / 和风用竖排书法与明朝体；报纸用报头大字 + 栏线；终端用等宽字；促销单用粗黑体斜切；棋谱用编号与网格；手写笔记用手写体。
- 和风房间常用的做法：`writing-mode: vertical-rl` 竖排标题与诗句；标题 2–4 字、字号是正文 6–10 倍；副标题小号宽字距（`letter-spacing: .4em`）；红色印章压在标题角上。
- 其他可用的强手段：巨型裁切字、字号极端对比、文字排成图形、网格编号、打字机错位、涂改与删除线、拉丁字母做结构而不只是装饰。
- 必须用系统字体回退也成立：非阻塞加载 Web 字体（见 `room-workflow.md`）。

## 8. 动效（持续 · 入场 · 叙事）

| 类型 | 用途 | 节奏 | 例 |
| --- | --- | --- | --- |
| **持续环境** | 让静态房间"活着" | 慢：20–120 s 周期，幅度小 | 星盘自转、花瓣/雪/萤火、水纹、吊饰摇摆、云气平移、胶片闪烁、霓虹不稳 |
| **入场揭幕** | 开场与切幕 | 中：3–12 s 分镜，有节拍 | 墨晕 → 落印 → 书写；小票逐行打印；报纸滚筒印出；电视开机雪花 |
| **叙事事件** | 剧情节点同步给所有人 | 快：0.5–3 s 冲击 + 余韵 | 时钟倒转、玻璃碎裂、红线断裂、版面再复印、墨迹晕开、落子 |

- 入场与叙事动效应当**从媒介本身的物理行为里找**（纸会被撕、被烧、被复印；屏幕会断信号；棋会落子），这是最容易产生新意的地方。
- 持续动效永不抢戏：低对比、低频、避开主窗中心。
- 叙事事件由 GM 触发，**所有人同时看到**（SealChat Events），结果状态写入 Storage 让迟到者也一致。
- 尊重 `prefers-reduced-motion`：关闭位移类动效，保留淡入淡出。

## 9. 母题 → UI 的翻译方法

第 3 节决定"整个房间是什么"，本节把具体物件落到 UI 上：

1. 读模组，列出 **关键物件**（怪谈车票：车票、月台、心电图；乐园：日历、时钟、文化祭装饰）。
2. 在选定的风格方向里，为物件分配角色：**主窗**、**标题 / 计数器**、**持续动效**、**叙事事件**。
3. 把**模组机制**物件化：时限 4 巡 → 4 张日历页；HO 两人 → 车票撕成两半；循环 → 时钟倒转 / 版面再复印。
4. 埋**不剧透的伏笔**：只用象征（月、兔、红线），不写出真相文字。

## 10. 反模式

- 按题材标签选风格（"克苏鲁就是星空黑"），或直接套参考原型 / 模板主题不改视觉。
- "新意"只停留在换配色、换母题图案，版面结构和动效与原型一模一样。
- 为了新意牺牲硬约束：主窗看不清、对话框读不清、底部太吵。
- 把秘密 / 真相写进房间（玩家可见！）。
- 主窗中心放持续动效或高对比装饰；所有元素都在动。
- 颜色没有叙事理由地堆砌。
- 全屏可交互层盖住其他可交互组件。
- 依赖位图大图（嵌入代码有 88 KB 上限，请用舞台图片对象承载位图）。
- 房间精心设计，对话框却是默认黑条；或对话框装饰压住名字区、正文区、右上角按钮。
