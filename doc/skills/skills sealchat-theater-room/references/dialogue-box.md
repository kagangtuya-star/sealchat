# 对话框底图：规格与设计方法

> 依据 SealChat 源码核对（`ui/src/types/theaterPresentation.ts`、`ui/src/views/theater/dialogue/TheaterDialogueOverlay.vue`、`ui/src/components/theater-presentation/TheaterPresentationEditorModal.vue`）。版本变化时以源码为准。

对话框是玩家盯得最久的界面。房间做得再好，对话框还是默认黑条，整套美术就会断一截。这里的产物是一张**透明底 PNG**，在「小剧场外观 → 对话框 → 对话框图片」上传；它不是 iForm 组件，不占嵌入代码体积。

## 1. 平台规格

| 项 | 默认值 / 行为 | 对设计的影响 |
| --- | --- | --- |
| 对话框位置 | 组合层（16:9）的 `x .05 · y .69 · 宽 .9 · 高 .28` | 1920×1080 舞台上是 **1728×302** @ (96, 745) |
| 底图铺法 | `object-fit: cover`，铺满对话框 | 宽高比必须与对话框一致，否则会被裁掉 |
| 推荐画布 | **1920×336**（= 1728:302.4，40:7） | 上传时会被压缩为 ≤1920 宽的 webp（保留透明），1920 宽刚好不再缩放 |
| 名字区 | 对话框内 `x .025 · y .065 · 宽 .34 · 高 .12` | 画布坐标 (48, 22) 653×40；字号 = 区高 × 0.85，单行 |
| 正文区 | 对话框内 `x .025 · y .28 · 宽 .95 · 高 .68` | 画布坐标 (48, 94) 1824×228；字号 = 组合层字号 × 1.2（组合层字号 `clamp(12px, .833cqw, 16px)`，相对对话框偏小） |
| 名字颜色 | 跟随**角色色**（每个角色不同） | 名札底色要能衬住各种角色色：用深色底 |
| 正文颜色 | 默认 `#F4F4F5`，可在编辑器改 | 浅色底的设计要在交付文档里写明"正文颜色改为 xxx" |
| 按钮 | 右上角「跳过 / 关闭」，固定 44px 屏幕像素 | 小屏上按钮相对更大：画布右上约 **180×90** 保持安静 |
| 支持格式 | PNG / WebP 静态图，APNG / 动态 WebP / WebM 动图 | 本 skill 产出静态 PNG；需要动效时再做动图 |

> 改了对话框宽高（例如做成窄条或两侧留白），就按新比例导出：`--size 宽x高`，模板用 `?w=&h=` 跟随。

## 2. 版面分区（1920×336）

```
┌──────────名札──────────┐  ← 上沿装饰带：彩旗 / 票号 / 吊星 / 印章 → ┐ ░按钮░ │
│  名字区 (48,22)         │                                              │ ░░░░░ │
├────────────────────────┘──────────────────────────────────────────────┴───────┤
│  正文区 (48,94) 1824×228：低对比纹理，可放极淡的涂鸦/纸纹                       │
│                                                                    角落伏笔   │
└──── 下沿：托盘 / 红线 / 卷轴杆，可出血到画布边缘 ──────────────────────────────┘
```

- **名札**：深色底 + 细描边 + 一点点缀色，宽度约 470–520，覆盖名字区并压过上框（"挂在框上"的层次感）。
- **上沿装饰带**：名札右侧到按钮区左侧、正文区以上（y < 94），是唯一可以"热闹"的区域。
- **正文区**：纹理对比度要低（叠加 alpha ≤ 0.08）。涂鸦、伏笔放到右下角，透明度 0.2–0.35。
- **下沿与左右边**：托盘、红线、卷轴杆、齿孔，可以从画布边缘出血。
- **透明区**：四角与名札、花饰之外保持透明，让轮廓不是一个死矩形。

## 3. 风格匹配（与房间同源）

对话框和房间说同一种视觉语言：从房间的概念卡（`design-essence.md` 3.3）出发，问"在这个媒介里，一段台词会印 / 写 / 显示在什么上面"。主窗是物件时，对话框常是它的缩小版；房间是一份媒介时，对话框是那份媒介里的"一条"——寻人启事的撕条、小票的一行、棋谱的注记栏、电视的字幕条、病历的医嘱栏。

下表是已有边框的对应方式，作为参考，不是选项范围：

| 房间主窗 | 对话框 | 名札 | 上沿带 | 下沿 |
| --- | --- | --- | --- | --- |
| 卷轴 `scroll` | 纸面 + 双线 | 墨色 / 深底 | 印章 | 左右卷轴杆 + 点缀色杆头 |
| 车票 `ticket` | 票面 + 齿孔 + 半圆缺口 | 墨色 | ADMIT ONE · 剪线 · 票号 | 齿孔 |
| 屏幕 `screen` | 半透明深色 + 双线 + 角括号 | 深底 | 吊星 | 角括号 |
| 花窗 `lattice` | 双框 + 回纹角 | 深底 | 印章 | 回纹角 + 点缀方块 |
| 黑板 `board` | 木框 + 黑板 | 墨紫 | 彩旗 / 磁贴 | 粉笔槽 + 粉笔 |

- 无论风格多大胆，第 1、2 节的分区规格不变：名札深底衬角色色、正文区低对比、按钮区安静。新意放在轮廓、材质、上沿带与下沿上。
- 配色沿用房间的配色方案，点缀色只出现在名札边、印章、红线这类小面积上。
- 有夜版 / 高潮版的房间，对话框也可以出一张同构图变体（只换底色与点缀明度），在切场景时换外观模板。
- 只用象征埋伏笔（月、兔、红线），不写任何秘密文字——对话框同样全程可见。

## 4. 工作流

1. **起步**：从 `templates/dialogue-box.html` 取画布、参考线、`?mode=` 约定与导出流程，美术按房间方向像 `rooms/paradise/07-dialogue-box.html` 那样手绘专属版本。只有快速草案才直接用 `?theme=<主题>&frame=<边框>` 套参数。
2. **对照**：设计台（默认模式）显示名字区 / 正文区 / 按钮区参考线与示例文字；专属版本再加一个"舞台合成预览"（主舞台 iframe + `?mode=stage` 的对话框），确认在舞台上不抢戏。
3. **导出**：
   ```bash
   python3 scripts/export_png.py templates/dialogue-box.html out.png --query "theme=school&frame=board"
   python3 scripts/export_png.py rooms/<模组>/07-dialogue-box.html rooms/<模组>/dialogue-box.png
   ```
   脚本会以 `?mode=export` 打开页面、用透明背景截图，并校验 RGBA 与四角透明。
4. **自查**：用图片查看器打开 PNG（透明区显示为棋盘格或深色）；确认右上角按钮区安静、正文区对比低、没有文字剧透。
5. **交付**：PNG + 设置说明（对话框位置是否保持默认、正文颜色、适用场景）写进房间 README。

## 5. 设计源文件约定

- 画布 `#art` 为 W×H 像素，所有美术画在一个 SVG 里（滤镜、裁剪、遮罩都只作用在面板形状内，透明区不留噪点）。
- `html, body { background: transparent }`；`?mode=export` 时隐藏参考线、示例文字与界面。
- `?mode=stage`：按 cover 铺满视口，叠加 SealChat 同款排版的示例文字，用于舞台合成预览与本地预览台。
- 字体非阻塞加载并提供系统回退；导出脚本留有虚拟时间预算等待字体。底图里尽量少用文字，必须用时选择回退后也成立的设计。
