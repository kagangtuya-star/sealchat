# 世界级演出

世界设置的「界面与扩展 → 演出与特效」保存全世界共享的特效和序列。聊天工具栏可向当前频道播放已启用的特效和序列。设置里的「测试」只在当前页面预览，可以测试尚未保存的草稿。

世界配置存放在 `worlds.world_presentation_json`，通过 `GET /api/v1/worlds/:worldId/presentation` 读取，通过 `PUT` 提交 `config` 和读取时的 `revision`。读取限世界成员，写入限世界所有者和管理员。修改后向当前世界连接发送 `world-presentation-updated`。场景配置仍存放在场景的 `serverState.theaterSequences`，两个范围互不继承。

服务端按当前频道从注册的世界所有者或管理员连接中指定一个自动触发端。该连接收到的实时 `message-created` 事件带有控制标记，使用共享运行时计算关键词、计数与冷却。服务端只接受当前控制连接针对已标记消息提交的结果，并校验目标和配置版本；手动播放也校验世界管理权限。播放以 `world-presentation-play` 广播给当前频道，客户端按 `executionId` 去重。

频道内没有打开普通聊天页的世界所有者或管理员时，自动触发暂停。控制端交接、重连或切换频道时，新控制端从下一条实时消息重新计数，不补算历史。计数和播放状态不入库，断线期间的播放不重放。悄悄话不触发公开演出。

世界级序列只执行无场景约束的 `effect.play`。已保存的组件点击触发、场景绑定的步骤、`scene.apply` 和 `object.trigger` 在编辑器中保留，并标识为需要小剧场。网页特效仍通过原有的沙箱 iframe 播放。
